# Auto-Organize Downloads

Solves the structural problem of chaotic Downloads directories by categorizing files into clear subfolders:
- `Images/`
- `Documents/`
- `Spreadsheets/`
- `Presentations/`
- `Videos/`
- `Audio/`
- `Installers/`
- `Archives/`
- `Code/`
- `Other/`

Optionally partitions files into year folders (`Documents/2025/`). Flags duplicate files automatically during scanning.

## Usage
- Run: `hermes-drive-index organize-downloads <folder>` or tool `auto_organize_downloads`.
